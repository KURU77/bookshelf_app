# 📚 マイ本棚 — バーコード蔵書管理アプリ

本のバーコードをスマホのカメラで読み取るだけで、自分の蔵書を記録・管理できる無料のWebアプリです。

**▶ 今すぐ使う: https://kuru77.github.io/bookshelf_app/**

アカウント登録は不要。データは自分の端末の中に保存されます。複数の端末で使いたい場合だけ、Googleアカウントでログインして同期できます。

## できること

- **バーコードで一瞬登録** — 本の裏表紙のバーコード（978始まり）をかざすだけ。書名・著者・出版社・表紙・ページ数を自動取得（openBD → Google Books → Open Library）。洋書や国内雑誌（491コード）にも対応
- **連続登録モード** — ONにすると読み取るたびに自動登録。本棚まるごとの登録に便利
- **置き場所ごとの一覧** — 「一人暮らし先」「実家」「研究室」など、本がどこにあるかで分類・絞り込み
- **ジャンル分け** — 自分だけのジャンルを自由に作って分類
- **表紙のグリッド表示** — 蔵書が表紙画像の一覧で見られる。長押しドラッグで並べ替え
- **読書の記録** — 読了/未読の管理、「いつ・何ページまで読んだか」の記録と進捗バー表示
- **検討中リスト** — 買うか迷っている本を別リストで管理。購入したらワンタップで蔵書へ移動
- **フリーワード検索** — 書名・著者名で即絞り込み
- **端末間の同期** — Googleアカウントでログインすると、パソコン・iPad・iPhoneで同じ本棚を使える。どの端末で編集しても自動でそろい、オフライン中の編集も接続時に統合
- **データの引き継ぎ** — ファイルの書き出し/読み込みで、ログインせずに端末間の移行も可能
- **PWA対応** — 「ホーム画面に追加」で普通のアプリのように使え、オフラインでも一覧を閲覧可能

## 使い方（スマホ）

1. https://kuru77.github.io/bookshelf_app/ を開く
2. **iPhone**: 共有ボタン →「ホーム画面に追加」 / **Android**: メニュー →「アプリをインストール」
3. 「＋ スキャン」を押してカメラを許可し、本のバーコードを枠に合わせる

友達に教えるときは、アプリ内の「⚙ 管理」→「📣 アプリを共有」からリンク送信・QRコード表示ができます。

## プライバシー

- 蔵書データは端末内（ローカルストレージ）に保存。同期機能を使わない限り、端末の外には送信されません
- 同期機能を使うと、蔵書データはGoogleのクラウド（Firebase）に保存され、ログインした本人だけが読み書きできます。アプリ内からいつでも削除できます
- カメラはバーコード読み取りにのみ使用し、映像の保存・送信はしません
- 詳細は [プライバシーポリシー](https://kuru77.github.io/bookshelf_app/privacy.html) をご覧ください

## 技術構成

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` / `app.js` | アプリ本体（フレームワーク不使用のシンプル構成） |
| `sync.js` | 端末間同期（Firebase Authentication + Cloud Firestore） |
| `firebase-config.js` | Firebaseの接続設定（公開前提の識別子のみ） |
| `firestore.rules` | クラウドのアクセス規則（本人のデータだけ読み書き可能） |
| `manifest.json` / `sw.js` | PWA設定・オフラインキャッシュ |
| `privacy.html` | プライバシーポリシー |

バーコード読み取りは BarcodeDetector API（対応ブラウザ）と [ZXing](https://github.com/zxing-js/library)（iOS Safari等）を併用。

### 同期のしくみ

- クラウド上では `users/{利用者ID}` に置き場所・ジャンル・並び順を、`users/{利用者ID}/books/{ISBN}` に本を1冊ずつ保存
- 本は1冊ごとに更新日時が新しい方を採用する。別々の端末で別の本を編集しても、どちらの変更も失われない。同じ本を2台で編集した場合は、後から編集した方が残る
- 削除した本は削除記録として残し、他の端末にも削除を伝える
- 受信は前回以降に変更された本だけを読むため、Firestoreの無料枠（読み取り回数）をほとんど消費しない

## 同期機能のセットアップ（運営者向け）

同期機能を使うには、Firebaseプロジェクトを1つ用意します。無料の Spark プランで動作し、課金を設定しなければ料金は発生しません。

1. [Firebaseコンソール](https://console.firebase.google.com/) で「プロジェクトを作成」（Googleアナリティクスは不要）
2. **Authentication** →「始める」→「ログイン方法」→ **Google** を有効化し、サポートメールを選んで保存
3. **Authentication** →「設定」→「承認済みドメイン」に `kuru77.github.io` を追加
4. **Firestore Database** →「データベースを作成」→ ロケーション `asia-northeast1`（東京）、**本番環境モード**で作成
5. **Firestore Database** →「ルール」に、このリポジトリの `firestore.rules` の内容を貼り付けて「公開」
6. **プロジェクトの設定** →「マイアプリ」→ ウェブ（`</>`）でアプリを登録し、表示される `firebaseConfig` の値を `firebase-config.js` に書き写してpush

`firebase-config.js` の値が空のあいだ、同期の欄には「準備中」と表示され、他の機能はそのまま使えます。

### 手元での動作確認（Firebaseエミュレータ）

```
npx firebase-tools emulators:start --only auth,firestore --project demo-bookshelf
```

エミュレータを起動し、`http://localhost:8123/?emulator` を開くと本番のFirebaseに接続せずに試せます（Firestoreエミュレータの実行にはJava 11以上が必要）。

## 開発者向け

```
python -m http.server 8123
```

で起動して http://localhost:8123/ を開くだけです（ビルド不要）。カメラはHTTPSまたはlocalhostでのみ動作します。
