# 📚 マイ本棚 — バーコード蔵書管理アプリ

本のバーコードをスマホのカメラで読み取るだけで、自分の蔵書を記録・管理できる無料のWebアプリです。

**▶ 今すぐ使う: https://kuru77.github.io/bookshelf_app/**

アカウント登録は不要。データはすべて自分の端末の中に保存され、外部には送信されません。

## できること

- **バーコードで一瞬登録** — 本の裏表紙のバーコード（978始まり）をかざすだけ。書名・著者・出版社・表紙・ページ数を自動取得（openBD → Google Books → Open Library）。洋書や国内雑誌（491コード）にも対応
- **連続登録モード** — ONにすると読み取るたびに自動登録。本棚まるごとの登録に便利
- **置き場所ごとの一覧** — 「一人暮らし先」「実家」「研究室」など、本がどこにあるかで分類・絞り込み
- **ジャンル分け** — 自分だけのジャンルを自由に作って分類
- **表紙のグリッド表示** — 蔵書が表紙画像の一覧で見られる。長押しドラッグで並べ替え
- **読書の記録** — 読了/未読の管理、「いつ・何ページまで読んだか」の記録と進捗バー表示
- **検討中リスト** — 買うか迷っている本を別リストで管理。購入したらワンタップで蔵書へ移動
- **フリーワード検索** — 書名・著者名で即絞り込み
- **データの引き継ぎ** — ファイルの書き出し/読み込みで端末間の移行が可能
- **PWA対応** — 「ホーム画面に追加」で普通のアプリのように使え、オフラインでも一覧を閲覧可能

## 使い方（スマホ）

1. https://kuru77.github.io/bookshelf_app/ を開く
2. **iPhone**: 共有ボタン →「ホーム画面に追加」 / **Android**: メニュー →「アプリをインストール」
3. 「＋ スキャン」を押してカメラを許可し、本のバーコードを枠に合わせる

友達に教えるときは、アプリ内の「⚙ 管理」→「📣 アプリを共有」からリンク送信・QRコード表示ができます。

## プライバシー

- 蔵書データは端末内（ローカルストレージ）にのみ保存。サーバーには何も送信されません
- カメラはバーコード読み取りにのみ使用し、映像の保存・送信はしません
- 詳細は [プライバシーポリシー](https://kuru77.github.io/bookshelf_app/privacy.html) をご覧ください

## 技術構成

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` / `app.js` | アプリ本体（フレームワーク不使用のシンプル構成） |
| `manifest.json` / `sw.js` | PWA設定・オフラインキャッシュ |
| `privacy.html` | プライバシーポリシー |

バーコード読み取りは BarcodeDetector API（対応ブラウザ）と [ZXing](https://github.com/zxing-js/library)（iOS Safari等）を併用。

## 開発者向け

```
python -m http.server 8123
```

で起動して http://localhost:8123/ を開くだけです（ビルド不要）。カメラはHTTPSまたはlocalhostでのみ動作します。
