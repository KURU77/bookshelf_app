プライバシーポリシー

最終更新日: 2026年9月29日

「マイ本棚 — バーコード蔵書管理」（以下「本アプリ」）は、利用者のプライバシーを尊重します。本ポリシーでは、本アプリが扱う情報について説明します。

1. 保存する情報

  • 蔵書データ（登録した本の情報・読書記録・置き場所・ジャンルなど）は、利用者の端末内（ブラウザのローカルストレージ）に保存されます。
  • アカウント登録は不要です。同期機能（次項）を使わない限り、蔵書データが端末の外に送られることはありません。

2. 端末間の同期（任意）

利用者がGoogleアカウントでログインして同期機能を使った場合に限り、次の情報を扱います。

  • Googleアカウントの情報：ログインの確認のため、メールアドレス・表示名・Googleが発行する利用者IDを受け取ります。パスワードを本アプリが受け取ることはありません。
  • 蔵書データ：複数の端末で同じ本棚を使えるよう、Googleが提供するクラウドサービス（Firebase Authentication・Cloud Firestore）に保存します。

クラウドに保存したデータは、ログインした本人だけが読み書きできるようアクセスを制限しています。データは同期の目的にのみ使い、第三者への提供や、広告・分析への利用は行いません。

アプリ内の「⚙ 管理」→「端末間の同期」→「クラウドのデータを削除して同期をやめる」から、クラウド上の蔵書データとログイン情報をいつでも削除できます。

3. カメラの利用

本アプリは、本のバーコード（ISBN・雑誌コード）を読み取る目的でのみカメラを使用します。カメラ映像は端末内でバーコードの検出処理に使われるだけで、撮影・保存・外部送信は一切行いません。カメラの使用は端末の設定からいつでも取り消せます。

4. 書籍情報の取得

書籍情報（書名・著者・表紙画像など）の取得のため、読み取ったISBNを次の公開データベースに送信します。送信されるのはISBN等の書籍コードのみで、利用者を特定する情報は含まれません。

  • openBD（openbd.jp）
  • Google Books API
  • Open Library
  • 表紙画像の取得元（Amazon・国立国会図書館サーチ等）

5. データの管理・削除

端末内の蔵書データは、アプリ内の削除機能、またはブラウザのサイトデータ削除により、いつでも削除できます。同期機能を使った場合のクラウド上のデータは、第2項の方法で削除できます。

6. 広告・解析

本アプリは広告を表示せず、アクセス解析ツールも使用していません。

7. お問い合わせ

本ポリシーに関するお問い合わせは、GitHubリポジトリのIssueまでお寄せください。
